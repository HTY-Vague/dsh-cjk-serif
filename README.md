# 中文衬线字体

<img src="assets/icon.png" width="72" alt="中文衬线字体">

让 DSH 里的中文用宋体（衬线），西文保持主题原字体。开关放在 **设置 → 通用设置**，默认开启。

## 解决什么问题

主题给正文指定的衬线字体，通常只覆盖西文字形。中文字符缺字时会按字体栈回退到 `Noto Sans SC`、`Source Han Sans SC` 这类无衬线字体，于是「主题已经切到衬线」和「中文仍是黑体」可以同时成立：问题出在中文字体回退上，与具体是哪个主题无关——西文字体大多不含汉字，不能指望它们来渲染中文。

本插件声明一个只覆盖 CJK 字符的字体族 `Dsh CJK Serif`，排在各主题的中文无衬线回退之前，让中文真正用上系统里已安装的宋体；西文字符不经过这个字体族，仍然使用主题自己的字体。

## 功能

- **总开关**：设置 → 通用设置 →「中文衬线字体」，紧跟在「外观」下面
- **按位置控制**：可折叠的分组开关，主区域、左侧边栏、右侧边栏、其他面板各一行
- **自动识别**：页面内容或窗口尺寸变化后重新扫描，其他插件新增的组件会自动归入对应区域
- **来源标注**：区域中包含第三方插件贡献的组件时，行尾以黑体、次要色、约 0.9 倍字号标注「来自 插件名」；应用自带的组件不标注
- **记住选择**：开关状态存 `localStorage`，刷新后保留

关闭总开关后，界面与会话中的中文恢复为主题原本的无衬线字体。

## 安装

**方式一：插件市场 / 插件管理器**

收录后在市场里搜索 `dsh-cjk-serif` 安装；也可以从本仓库目录安装。

**方式二：命令行**

```sh
dsh plugin --profile desktop add github:HTY-Vague/dsh-cjk-serif
```

把 `desktop` 换成你实际使用的 profile 名（例如 `web`）。首次安装后刷新一次页面；之后切换开关即时生效。

## 使用

总开关开启时：

- 中文：使用系统里已安装的第一个中文衬线字体
- 西文：不受影响，仍是当前主题的字体
- 代码块：保持等宽字体

「按区域控制」默认收起，点开后可以单独关闭某个区域的中文衬线。区域开关只在总开关开启时可用，改动会立即应用到对应区域。

> 区域是插槽级粒度：同一个列表插槽里的多个组件共用一个容器，无法逐个开关，区域开关会同时作用于它们。

## 字体来源

按以下顺序取系统里第一个可用的字体：

`Noto Serif CJK SC` → `Noto Serif CJK TC` → `Noto Serif CJK` → `Source Han Serif SC` → `Source Han Serif TC` → `Source Han Serif` → `Noto Serif SC` → `Noto Serif TC` → `Songti SC` → `STSong` → `SimSun`

常见环境：Linux 装 `fonts-noto-cjk` 即有 Noto Serif CJK SC；macOS 自带 Songti SC；Windows 自带 SimSun。一个都没有时，开关不会报错，但中文外观不会变化。

## 实现说明

- 字体族通过 `@font-face` 声明，`unicode-range` 限定在 CJK 区块，所以拉丁字母、数字、符号不会命中它
- 覆盖的变量：运行时从页面实际生效的字体栈里读取（属性名匹配 `font`、`serif`、`prose` 的自定义属性），在每个变量前插入中文字体族，并保留原有字体作为回退
- 如果主题自己提供了字体方案，也会一并做对应处理；没有启用主题时，覆盖基础样式栈，并保留用户自定义的文本字体设置
- 区域开关通过给插槽容器加 `data-cjk-region-font="serif|sans"`、并在该元素上覆盖同名变量实现，嵌套区域可以独立覆盖父级
- 只声明 400 字重：`local()` 源只能取到字族的常规体，声明 700 会让粗体静默丢失；只留 400，让浏览器合成粗体，粗体可见
- 不改包外文件，也不碰系统 fontconfig；停用插件即可完全恢复

## 已知限制

- 区域按插槽名做粗粒度归类，用了非常规插槽名的插件会落到「其他面板」
- 同一插槽内多个组件无法单独控制，见上文「使用」
- 代码字体（名字含 `code`、`mono`、`terminal` 的变量）有意保持不变，仍用等宽字体

## 卸载

在插件管理器里停用或移除 `dsh-cjk-serif`，界面即恢复主题原始字体。
